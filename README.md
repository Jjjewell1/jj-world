# JJ Jewell 3D Portfolio — Digital Forge v3

A first-person-style 3D portfolio environment.

Controls:
- Drag: look
- W/A/S/D or arrows: move
- Mouse wheel: move forward/back
- Click a glowing core: inspect
- Bottom navigation: jump to a room
- T: JJ terminal
- Esc: close panel

The environment contains six rooms representing Web, Infrastructure, Local AI, Cybersecurity, Fabrication, and the Operator/Career story.

Content is based on the supplied portfolio/resume material and existing portfolio direction.
